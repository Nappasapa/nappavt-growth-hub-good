Clip storage

Manually uploaded video files can be cleaned up automatically after posting. Twitch clips stay on Twitch and use 0 MB of Supabase video storage. Your post history stays in the Growth Hub.
Default: 7 days. Use “Keep this video” on any post you never want auto-deleted.

Social analytics connections

Credentials and OAuth refresh tokens live only on Craftnode. They are never placed in this HTML or Supabase dashboard state.

YouTube

Craftnode env: YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET. Enable YouTube Data API v3 + YouTube Analytics API. Redirect URI defaults to http://127.0.0.1:53682/callback.

TikTok

Craftnode env: TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET. Add Login Kit + TikTok API / Display API with video.list. Redirect URI defaults to http://127.0.0.1:53683/callback/.
